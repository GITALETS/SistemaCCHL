Manual de Usuario

Bienvenido al Generador de Constancias CCHL. Este sistema permite generar automáticamente los formatos de habilidades laborales (DC-3) a partir de los datos de Excel.

Paso 1: Cargar Archivos (Pestaña 1)

  • 1. Archivo de Créditos: Sube el Excel principal que contiene las hojas CAPPA y CAPPI con la lista de trabajadores y sus requerimientos.
  • 2. Plantilla Word: Sube el archivo .docx base (CCHL MODIFICABLE). Este documento se usará como plantilla para la generación.
  • 3. Kardex: Selecciona de forma múltiple los archivos Excel de Kardex individuales de los trabajadores para obtener las fechas de término reales.

Paso 2: Configuración (Pestaña 3)

  • Antes de generar documentos, ve a la pestaña Configuración y Catálogos.
  • Selecciona el perfil de tu zona para cargar a los representantes del patrón y trabajadores. Si no existe, crea un nuevo perfil.
  • Revisa los mapeos de columnas por si el formato de Excel ha cambiado.

Paso 3: Generación (Pestaña 2)

  • Selecciona un trabajador en la lista de la izquierda.
  • Verifica sus datos (CURP, Puesto). Si es necesario, edítalos o añade un curso manualmente con el botón verde.
  • Marca la casilla "Expediente Completo / Carpeta Generada" para marcarlo como finalizado en el listado.
  • Si el curso no tiene fecha en el Kardex, puedes usar el botón Fechas Aleatorias a Vacíos.
  • En la parte derecha verás una previsualización de cómo se verá el formato impreso.
  • Presiona Guardar en Word (.docx) para descargar el documento final generado.

El proceso no guarda datos en servidores externos; toda la información se procesa localmente en tu navegador.
